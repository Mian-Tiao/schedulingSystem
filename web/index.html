給組員的說明
  • 共用檔:base.css(統一風格)與 common.js(API 呼叫、時間格式)—— 請「不要改」,大家共用。
  • 你只需要編輯自己負責的那一頁 HTML(含頁面內的 <script>)。
  • 套用 base.css 提供的 class(.btn .card .table .badge .field .input …)外觀就會一致。
  • 若你的頁面需要特殊樣式,請「自己建立一個 css 檔」(例如 orders.css)再在該頁引入,不要動 base.css。
  • 所有資料操作都透過 common.js 的 api(),例如 await api('/orders')。
